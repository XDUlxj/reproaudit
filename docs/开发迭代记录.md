- 已完成：使用 SQLAlchemy 2.x 实现 PostgreSQL/SQLite 共用表结构。
- 已完成：实现四类 Entity 的 Repository，支持稳定 ID 幂等重放和冲突检测。
- 已完成：实现 Task–ResearchResource 关联、Spec 版本关系和 Run 生命周期更新。
- 已完成：实现 PostgreSQL 启动探活失败后的显式 SQLite 降级。
- 已完成：为 SQLite 开启外键约束，使测试行为尽量与 PostgreSQL 一致。
- 已完成：实体快照在 PostgreSQL 使用 JSONB，SQLite 降级时使用兼容 JSON。
- 已完成：Task 的 answer 使用独立 TEXT 列，便于直接展示与查询。
- 边界：本轮没有持久化 Agent State、Message、检索索引或 Artifact 文件内容。
